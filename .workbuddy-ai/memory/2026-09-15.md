## Backend + Ma'lumotlar bazasi qo'shildi (2026-09-15)
- Foydalanuvchi backend va ma'lumotlar bazasini so'radi
- Texnologiya: Node.js + Express + SQLite (better-sqlite3) + JWT (jsonwebtoken) + bcryptjs
- Backend: server/ papkasida, port 5000

### Backend tuzilmasi:
- server/package.json - Express, better-sqlite3, bcryptjs, jsonwebtoken, cors
- server/src/index.js - Express app entry, CORS, routes mounting
- server/src/db/database.js - SQLite connection, 15 ta jadval (users, libraries, books, readers, activities, reports, tasks, events, inventory, documents, appeals, notifications, kpi_data, audit_log, settings), row/object conversion helpers
- server/src/db/seed.js - Seed data (9 users, 6 libraries, 40 books, 12 readers, 8 activities, 5 reports, 5 tasks, 5 events, 7 inventory, 5 documents, 4 appeals, 7 notifications, 8 KPI, 6 audit logs)
- server/src/middleware/auth.js - JWT token generation + verification middleware + role-based access
- server/src/routes/auth.js - login, me, logout, register endpoints
- server/src/routes/crud.js - Generic CRUD factory for 9 entities (libraries, books, readers, activities, events, inventory, documents, appeals, kpi-data)
- server/src/routes/special.js - Special routes for users (password hashing), reports (submit/review), tasks (status update), notifications (user-specific, mark read), settings, audit-log, dashboard/stats

### Frontend integratsiyasi:
- src/utils/api.js - API client (fetch wrapper, JWT token management, STORAGE_KEYS -> API endpoint mapping)
- src/context/AppContext.jsx - to'liq qayta yozildi:
  - localStorage o'rniga API dan ma'lumot yuklanadi (useEffect + token check)
  - collections state (ref bilan) - getCollection sinxron ishlaydi
  - Generic CRUD: optimistic update + background API call
  - Specific methods (createUser, createReport, createTask): API call + state update
  - login() endi async - authApi.login() + JWT token
  - Session restore: token check + authApi.me()
- src/pages/auth/Login.jsx - handleSubmit endi async (await login())
- vite.config.js - /api proxy qo'shildi (localhost:5000 ga forward)
