## Session persistens tuzatildi
- Muammo: sahifa yangilanganda avtomatik admin/admin123 bilan kirib qolar edi
- Sabab: AppContext.jsx da token bekor bo'lganda auto-login (admin/admin123) kodiga qaytgan
- Hal qilish:
  1. Auto-login (admin/admin123) to'liq olib tashlandi
  2. api.js ga getCachedUser() va setCachedUser() funksiyalari qo'shildi (localStorage'da user saqlash)
  3. AppContext.jsx yangilandi:
     - Login → token + cached user localStorage'da saqlanadi
     - Page refresh → cached user darhol ko'rsatiladi (UI flash yo'q), keyin token verify qilinadi
     - Token valid → yangi user ma'lumoti bilan yangilanadi
     - Token invalid → login sahifasi ko'rinadi (avtomatik admin emas!)
     - Logout/updateUser/resetAllData ham cached user ni tozalaydi/yangilaydi
  4. Har bir foydalanuvchi o'z token'i bilan qoladi — sayt yangilanganda ham
